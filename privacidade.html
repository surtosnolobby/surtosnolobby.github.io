Política de Privacidade

SurtosNoLobby Radar · atualizada em 19 de novembro de 2026

O SurtosNoLobby Radar é uma ferramenta de uso interno do canal SurtosNoLobby. Ela publica, nas contas do próprio canal, cortes curtos de lives que foram aprovados manualmente pelo dono do canal.

Quem usa

A ferramenta é usada apenas pelo dono do canal SurtosNoLobby, nas contas do próprio canal (YouTube, TikTok e Instagram @surtosnolobby). Ela não é oferecida ao público e não coleta dados de outras pessoas.

Dados que acessamos

Google / YouTube: envio de vídeos, para publicar os cortes aprovados no canal; e leitura, para confirmar o canal autorizado e a situação dos vídeos enviados.

TikTok: informações básicas do perfil (open_id e nome de exibição), para confirmar a conta conectada; e envio de vídeos, como rascunho ou publicação direta na conta @surtosnolobby.

Não acessamos e-mails, contatos, mensagens, arquivos, histórico de navegação nem dados de outras contas.

Como os dados são usados e guardados

Os tokens de acesso ficam apenas no computador do dono do canal. Eles não são vendidos, compartilhados nem enviados a terceiros. Não usamos os dados para publicidade nem para treinar modelos de IA.

Como revogar o acesso

Google: myaccount.google.com/permissions. TikTok: no app, em Configurações e privacidade → Segurança → Apps e serviços.

Uso dos dados das APIs

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado. O uso das APIs do TikTok segue os Termos de Serviço para Desenvolvedores do TikTok.
